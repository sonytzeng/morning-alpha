# 股票證據與評估分類修復（2026-10-19）

本變更修復兩個可重現的工程問題，並保留原資料門檻。網站 Live696 已於前一階段發布；本次沒有網站來源變更，也不部署正式 Worker 或接納新正式來源。

## 完整資料與選股條件分開

原 V1 把四季資料完整、但有些季度優於預估、有些低於預估的個股標成「缺財報」。現在在其他當下可知必要證據都完整時，這類個股完成評估並標記 `NONE`，不產生 `INTACT`、`WATCH`、`READY` 或機會卡。真缺值、失效、晚於截止時間及缺事件映射仍被阻擋。

全域查詢不完整或稍後發現歷史報價衝突時，整個 Universe 的狀態與計數一起歸零為 `BLOCKED`。保留原篩選門檻、反證及會員投影限制；沒有為了產生推薦而放寬條件。

39 項針對性回歸通過。另一位執行者獨立測試 33 組情境、24 組順序、24 組輸入不突變與32組會員投影。這是有限程式審查，不是正式安全掃描或 Production E2E。

## 離線官方報表解析

預設 CP950/Big5 全檔嚴格解碼維持原行為。明確 opt-in 的 opaque profile 只允許精確附註 namespace/QName、`escape=true` 及已驗證 context 的孤立不可解碼正文；所有 markup、屬性、namespace、resource 及 numeric 內容仍嚴格驗證，完整文件及後段衝突仍會檢查。未列入的 namespace 維持拒絕，沒有 ignore、replace 或截斷資料。

另一明確 opt-in 的 individual profile 接受真實 `REPORT_ID=A` 與正確 entity/context，保留個別報表基礎，不冒充 `C` 合併報表、普通股口徑完整准入或同口徑四季完成。離線測試共32項（新增10項），原預設有效輸出逐字典相同。

## 尚未解決的資料能力

已核對的 Fugle／TWSE 逐股法人接口提供「股數」，市場法人接口提供「市場總金額」，均不能直接供應 V1 要求的逐股實際法人 TWD 金額。不得以股數乘收盤價代替，也不能據此斷言所有其他產品都不存在。取得最新 historical consensus 也不能證明公告前版本；ordinary-share／ADR、幣別、會計基礎必須分開。

V2 與 Entry 是既有不同版本研究方法，不是偷偷修補 V1 的資料替代品。它們的准入、自然前向與發布條件依原文件保留，不能保證每日一定有 `READY`。

必要公開報表已持續有界取得並保存真實收到時間與原件指紋。離線解析結果不回填舊截止時間，不寫入正式 canonical tables，也不把候選筆數當成正式評估筆數。實際單季覆蓋保存在獨立非敏感收據；缺 diluted 或金融業 revenue 的項目如實保留。
