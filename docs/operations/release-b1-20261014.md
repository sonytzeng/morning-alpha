# Morning Alpha B1 批次推薦 Reader 發布清單

本批修復已保存的個股證據未接入Reader，以及2330同一收盤時間的 Core缺量資料覆蓋有效股票量價。正式推薦品質門檻、Canonical Decision及Report Producer不變。

## 根因與真實證據

10/13正式報告保存72份 capture、3096列量價；72份 payload hash在資料庫內重算全部通過。Producer Run ID是correlation_id，與Canonical Snapshot ID不同，必須分開綁定，不能強行視為同一ID。

2330同時間缺量Core與完整股票資料有30組；依舊排序最新20日有17日缺量，改為完整、同價格的整筆股票bar後缺量0。資料庫只回傳計數、分類及指紋；原始行情匯出被安全審查拒絕，未複製至本機或Repository。這不是完整正式Reader新版本E2E，後者需核准部署後唯讀驗收。

正式10/13 Producer評估時間早於Canonical快照提交1.639824秒；兩者不能要求完全相等。修復保留Producer cutoff／generated_at三者一致且不晚於提交；每份capture接收時間不晚於Producer cutoff。晚到、無效時間、跨Revision與Run仍拒絕，不改評估門檻。

## 精確修改

- `supabase/functions/get-report-payload/index.ts`：讀同一報告內保存 capture，原會員／出版／Canonical gate保留。
- `supabase/functions/_shared/recommendation-stock-evidence.ts`：驗報告Canonical revision、Producer correlation ID、同Producer cutoff與不晚於提交、hash、來源session及availability；不發Provider請求。
- `supabase/functions/_shared/decision-v1-evidence.ts`：選取完整同日bar，不把不同來源價量拼接。價格衝突仍拒絕。

唯一部署Function：`get-report-payload`，保留custom Auth及verify_jwt=false。其他共享檔雖被引用，不部署其餘Producer。Migration、Secret、Cron、Auth/RLS變更均無。精確檔案雜湊在 `staged-b1-transition-20261014.json`。
