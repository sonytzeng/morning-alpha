本批從PR230的a5c0ae5fc81661de87cb32e9ad9ebced2f394170抽出Runtime，沒有會員、付款、Publication Migration或UI。原PR230維持Draft。

## 最小正式範圍

唯一SQL：`20261012054120_vnext_daily_research_runtime_candidate.sql`。

新增Function：`vnext-daily-research-v1`。更新唯一Caller：`recommendation-v2-forward-worker-v1`，僅非阻塞enqueue，不讓市場、Report或LINE等待研究。其餘依賴按來源閉包逐檔列出，不部署依賴所屬的其他Function。

新增Worker在config明確verify_jwt=true，不改其他Function設定；額外internal header使用既有CRON_SECRET，無service-role／Owner browser fallback。自然Caller與continuation使用已具名既有RECOMMENDATION_GATEWAY_ANON_JWT，而不是假設SUPABASE_ANON_KEY必定是合法Gateway JWT。沿用既有SUPABASE_URL、SUPABASE_SERVICE_ROLE_KEY與CRON_SECRET，不新增或改Secret。部署前若不存在合法Gateway JWT則停止，不試其他Credential。

新增8個私有RLS表、Run／Checkpoint／Lease／SourceRevision、不可變Prediction、Outcome及Audit。Owner只讀RPC沿用正式Owner predicate；Free／Premium／Anonymous不能取得私人研究或寫Worker。

精確差異在 `staged-c-transition-20261014.json`；原39檔依賴閉包是靜態source清單，其中main本來已有的檔案不重複放進diff。新增的parser原型腳本只作隔離一致性測試，不部署。

10/14有界官方唯讀：TWSE61檔＋TPEx11檔，72檔分類完整；2330官方10月量價8列，最新10/13。first_seen／available_at保留10/14實際取得時間，published_at未知仍null。沒有把新取得資料倒填舊cutoff，沒有建立正式Forward。

## 實際隔離驗收

真PostgreSQL＋PostgREST＋HTTP Worker：8表RLS、Owner read ALLOW／anon/free/paid DENY、並行Lease、expired lease恢復、stale fence拒絕、216項鎖定交易原子性、晚到拒絕、無重複發布、append-only、Outcome maturity及3次有界Retry通過。合成控制沒有買點證據，所以216項全部INSUFFICIENT，正式Forward／Outcome皆0。

新增Gateway continuation狀態檢查；401等錯誤不再被當成成功HTTP回應。只記錄去敏分類，不輸出憑證，Core／V2的既有結果不受background失敗影響。

CSV加入128欄／25000列／32768字單格的結構上限，在建立物件前先過濾公司；財務HTML改用線性tag掃描，5000列／128欄及單格上限。這是解析資源限制，不降低財務或投資品質門檻。Malformed provider控制及有效繁中表格皆驗證，原型parser參考同步保持逐位元一致；原型不是可執行的正式資料取得工具。

## 正式發布與精確回滾

需要Sony對新PR與SHA、唯一SQL、新Worker及唯一Caller具名核准。順序：SQL→新Worker→負向Auth及Owner唯讀→Caller非阻塞hook。不人工呼叫Report、LINE或產生歷史Forward，等新合法交易日自然啟用。

回滾先回復V2 Caller main精確原19檔及verify_jwt=true，停用新Worker執行；只撤銷新Worker寫入RPC的service EXECUTE，保留Owner鑑識讀取與全部Prediction／Outcome／Audit。Fresh DB已驗證撤銷後仍可Owner讀，且不可變歷史指紋完全一致，不DROP／DELETE。

會員內容仍須Quality、PIT、Licensing及Sony核准。29項歷史研究未獲公開資格，C成功不會自動發布。正式Natural Forward仍NOT_ENABLED，策略價值INSUFFICIENT_SAMPLE，五日0/5。
