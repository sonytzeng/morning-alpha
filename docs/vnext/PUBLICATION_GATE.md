# 公開安全 Gate
資料→source→license→PIT→quality→relevance→horizon→conditions→copy→immutable approval→server entitlement。
未知權利、任一缺口、過期review、撤回審核、hash不一致、歷史重播皆不得提供會員。
研究原文不能叫正式推薦、保證獲利、穩賺或高勝率。
Owner 可讀研究；Free只讀approved/free最多3筆；Premium只讀approved/free或premium，最多100筆。
Client沒有tier或user_id參數；改query/localStorage/user_metadata不改權限。
Owner predicate、Academy private server resolver、既有訂閱權益不修改。
raw tables forcedRLS Owner only；anonymous無RPC execute；member不取得hash/schema/raw payload。
publication_audit append-only最新review可撤回，不UPDATE歷史；gate version固定。
Source license必須明確涵蓋storage/derived/commercial/redistribution與attribution。
目前沒有Production publication approval producer、無public會員資料輸入或自動promotion。
